# Your Special Day — Lê Thị Cẩm Đào (22/11)

Trang web chúc mừng sinh nhật chủ đề **Kiến trúc Trung Hoa trung đại** dành tặng **Lê Thị Cẩm Đào** (toàn bộ ảnh nền 16:9 và ảnh tháp đã nhúng sẵn trong `index.html`).

## Cách đưa lên GitHub Pages
1. Tải `index.html` lên Repository GitHub (có thể thêm `birthday-xinh-iu.mp3` cùng thư mục để phát nhạc Full bài 03:24).
2. Vào **Settings → Pages** → mục **Branch** chọn `main` (`/root`) → nhấn **Save**.
3. Để xem trước khi chưa tới `00:00:01 22/11`, bấm **3 lần liên tiếp** vào dòng `✦ A SPECIAL GIFT FOR YOU ✦` hoặc thêm `?preview=1` vào cuối link.
